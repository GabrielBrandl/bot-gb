# PROJECT BRIEF — GB Systems Omnichannel

Multi-tenant SaaS for WhatsApp + Instagram customer service, automation, AI agent, Kanban CRM, mass campaigns and payments (ASAAS).

Brand: **GB Systems** (blue `#2F6BFF` + purple `#8B5CF6`, dark UI).

## Stack

- Backend: NestJS + TypeScript
- DB: PostgreSQL + Prisma
- Cache/queues: Redis + BullMQ
- Realtime: Socket.io
- WhatsApp: Evolution API
- Instagram: Meta Graph API
- AI: OpenAI / Anthropic adapters
- Frontend: React + Vite + Tailwind
- Deploy: Docker / EasyPanel
